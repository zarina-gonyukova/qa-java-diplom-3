# Stellar Burgers UI автотесты

Дипломный проект по курсу «Инженер по тестированию: от новичка до автоматизатора»  (Яндекс Практикум).  Цель — проверить ключевые пользовательские сценарии: регистрацию, авторизацию и работу конструктора бургеров.




## Стек

- Java 11
- JUnit 5
- Selenium WebDriver 4
- Maven 
- Allure Report 2

## Что проверяют тесты

- Регистрация нового пользователя с валидными данными
- Регистрация с некорректным/коротким паролем (отображение ошибки)
- Авторизация по email и паролю из формы входа
- Авторизация через кнопку в личном кабинете
- Авторизация через кнопку в форме регистрации
- Авторизация через кнопку в форме восстановления пароля
- Переход между разделами конструктора: «Булки», «Соусы», «Начинки»

Всего реализовано 9 автотестов, сгруппированных в 3 набора:
- `RegistrationTest` — сценарии регистрации
- `LoginTest` — сценарии входа
- `ConstructorTabsTest` — переключение вкладок конструктора

## Результаты прогона тестов

Все автотесты выполняются успешно как по отдельности, так и в составе полного прогона.  
После запуска `mvn clean test` генерируются результаты в директории `target/allure-results`, на основе которых строится HTML‑отчёт Allure.

Итоговый отчёт содержит:
- 9 test cases
- 3 suites (Registration, Login, Constructor)
- 100% успешное прохождение тестов

Отчёт корректно отображает статус каждого теста и его шаги, что подтверждает корректную работу автотестов и конфигурации Allure.

## Как запустить тесты и отчёт

1. Склонировать репозиторий и установить зависимости Maven.
2. Запустить тесты:
   ```bash
   mvn clean test
   ```  
3. Сгенерировать и открыть отчёт Allure (при настроенном плагине):
   ```bash
   mvn allure:serve
   ```  

После выполнения этих шагов в браузере откроется интерактивный Allure‑отчёт с результатами последнего прогона тестов.
